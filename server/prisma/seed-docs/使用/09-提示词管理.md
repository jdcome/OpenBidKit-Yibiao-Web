# 提示词管理使用教程

提示词管理仅管理员可见。在左侧点击 **提示词管理**，进入 **招标解析与废标检查提示词** 页面。

这里用于维护系统调用模型时使用的提示词。它会影响招标解析、废标检查、镜像采购需求等能力的输出质量，因此修改前要先明确目的，修改后要用测试项目验证。

![提示词管理标注](/docs/images/标注/23-提示词管理标注.png)

**看这里：**

- **① 按模块分组查看：** 先确认提示词属于招标解析、废标检查、技术方案等哪个模块，再决定是否调整。
- **② 谨慎切换启用：** 关闭提示词会影响对应解析链路，尤其不要随意停用内置必填项。
- **③ 编辑正文并保存：** 修改正文时保留输出格式、字段名和禁止事项，保存后再用测试项目验证效果。
- **④ 新建或恢复默认：** 自定义提示词适合局部试验；误改内置项时优先恢复默认，再重新调整。

## 第一步：理解页面分组

页面按模块分组展示提示词：

- **招标解析：** 用于项目概述、技术评分、投标流程、合同条款等招标文件解析任务。
- **废标检查：** 用于识别无效投标、废标项和硬性响应风险。
- **镜像采购需求：** 用于从招标文件中抽取适合镜像生成的采购需求结构。

每行提示词会显示：

- 名称；
- itemKey；
- 输出格式；
- 是否启用；
- 操作按钮。

**看这里：** 带 **系统** 标记的是模块共用系统提示词；带 **内置** 标记的是系统默认提示词；带 **必填** 标记的项目会影响核心解析结果。

## 第二步：编辑内置提示词

找到需要调整的提示词，点击右侧 **编辑**。

可以修改：

- 标签；
- 说明；
- 分组；
- 输出格式；
- 是否必填；
- 是否启用；
- 提示词正文。

修改完成后点击 **保存**。

**看这里：** 修改提示词正文时，不要删除原本要求模型输出 JSON、字段名、表格或 Markdown 格式的关键约束。格式约束被破坏后，后台任务可能无法解析结果。

## 第三步：启用或禁用提示词

在列表中可以直接切换 **启用** 开关。

适合禁用的情况：

- 某个解析项暂时不需要；
- 某个自定义提示词效果不好；
- 想对比启用前后的结果差异。

不建议禁用的情况：

- 内置必填项；
- 项目概述、评分标准、投标流程等核心招标解析项；
- 正在生产使用的解析链路。

**看这里：** 关闭内置必填项时，系统会二次确认。确认后该项不再参与招标解析和必填校验，可能影响后续目录生成或检查结果。

## 第四步：恢复默认

如果单个内置提示词改坏了，点击该行 **编辑**，再点击 **恢复默认**。

如果需要把所有内置提示词正文恢复到系统默认值，点击页面右上角 **恢复全部默认**。

**看这里：**

- 恢复默认会覆盖内置项的正文编辑。
- 自定义提示词不会被删除。
- 标签、分组等元数据按当前实现保留，主要恢复的是提示词正文。

## 第五步：新建自定义提示词

点击右上角 **新建自定义**，填写：

1. **所属模块：** 选择招标解析、废标检查或镜像采购需求。
2. **itemKey：** 字母开头，只能包含字母、数字和下划线，并且必须唯一。
3. **标签：** 页面上显示的名称。
4. **说明：** 写清楚这个提示词解决什么问题。
5. **输出格式：** 根据任务选择 Markdown 或 JSON。
6. **必填项：** 只有确实必须参与结果校验时才勾选。
7. **提示词正文：** 写清楚输入、处理规则、输出格式和禁止事项。

填写完成后点击 **创建**。

**看这里：** 自定义提示词适合做小范围增强，不建议一次新增太多。每新增一个，都要用测试项目确认效果。

## 第六步：验证修改效果

提示词保存后，建议按下面顺序验证：

1. 准备一个测试项目，不要直接拿生产项目反复试错。
2. 重新执行对应功能，例如招标解析或废标项检查。
3. 查看结果是否更准确。
4. 如果任务失败，优先检查提示词是否破坏了输出格式。
5. 效果不好时，恢复默认或关闭自定义提示词。

**看这里：** 提示词管理改变的是模型行为，不是页面样式。保存成功不代表效果一定变好，必须通过实际任务验证。

## 使用建议

- 每次只改一个或少量提示词，方便定位效果变化。
- 修改前复制一份原正文留底。
- 不要在提示词中写 API Key、客户秘密、数据库密码或固定生产数据。
- 需要 JSON 输出的提示词，要保留字段名和结构约束。
- 生产环境调整前，先在测试项目验证。
- 如果连续出现解析失败，先恢复默认，再逐项排查。
