# 问题FAQ使用教程

在左侧点击 **问题FAQ**。这里用于提交使用问题、补充截图、查看管理员回复，并把常见问题沉淀下来。

## 第一步：查看已有问题

进入页面后，系统会显示所有问题记录。每条记录会显示当前状态、回复数量、提问人和更新时间。

**看这里：**

- **待处理：** 问题已经提交，等待管理员回复或处理。
- **已解决：** 管理员或提问人已经确认问题解决。
- **已关闭：** 问题不再继续跟进，通常用于重复问题或无需处理的问题。
- **回复数量：** 有回复的记录会显示“几条回复”，点击后可以查看完整对话。

## 第二步：提交新问题

点击右上角 **＋ 提交问题**，在文本框里描述遇到的问题，然后点击 **提交**。

建议按下面的格式写：

1. 我在哪个页面遇到问题。
2. 我点击了哪个按钮。
3. 我原本希望系统做什么。
4. 系统实际出现了什么提示、报错或异常现象。
5. 如果和某个项目有关，写清楚项目名称或编号。

**看这里：** 问题描述是必填项。只写“不能用”“出错了”会让管理员很难判断原因，建议把操作步骤写清楚。

## 第三步：上传截图

如果问题和页面显示、报错提示、导出结果有关，建议点击截图区域的 **＋** 上传图片。

系统会自动压缩图片，减少上传体积。可以上传多张截图，用来说明操作前后、错误提示和页面位置。

**看这里：**

- 截图里不要包含 API Key、数据库密码、客户敏感内容或个人隐私。
- 如果必须展示客户文件内容，建议先打码再上传。
- 上传错图片时，可以点击缩略图上的 **×** 移除。

## 第四步：查看回复并补充说明

提交后回到问题列表，点击对应问题进入详情页。

在详情页可以看到：

- 原始问题描述。
- 上传截图。
- 管理员回复。
- 其他补充说明。
- 当前处理状态。

如果管理员需要更多信息，可以在底部输入框继续补充说明，必要时继续上传截图，然后点击 **发送**。

**看这里：** 普通用户可以补充说明；管理员回复会带有 **管理员** 标记，方便区分。

## 第五步：管理员处理问题

管理员进入问题详情后，可以直接回复问题，也可以修改状态。

建议处理顺序：

1. 对可立即回答的问题，直接在回复框写解决方法并点击 **发送**。
2. 需要用户补充材料时，明确说明需要什么截图、项目名称或操作步骤。
3. 问题解决后，将状态改为 **已解决**。
4. 重复问题、无效问题或无需继续处理的问题，可以改为 **已关闭**。

**看这里：** 状态变更会保存到问题记录中，后续其他用户查看同类问题时，也能快速判断处理结论。

## 使用建议

- 先搜索和浏览已有问题，避免重复提交。
- 提交问题时写清楚页面、按钮、期望结果和实际结果。
- 截图尽量截完整页面，不要只截一个看不出位置的小角落。
- 涉密内容先打码，再上传。
- 管理员回复后，如果问题已经解决，及时确认并让管理员更新状态。
