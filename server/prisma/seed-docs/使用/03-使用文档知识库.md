# 知识库使用教程

在左侧点击 **知识库**，根据资料类型进入 **方案模板库**、**工具模板库**、**公司资质库** 或 **人员资质库**。

知识库的作用不是替你直接生成标书，而是把公司常用资料、历史方案、工具截图、资质证书和人员证书先整理好。后续生成技术方案、扩写方案或检查标书时，就能更容易找到可复用材料。

## 第一部分：维护方案模板库

在左侧点击 **知识库 → 方案模板库**。这里适合上传历史技术方案、服务方案、项目案例、标准响应材料和可复用 Markdown/Word/PDF 文件。

![文档知识库](/docs/images/标注/12-文档知识库.png)

## 第一步：新建文件夹

点击右上角 **新建文件夹**，输入分类名称后点击 **创建**。

建议按下面的方式分类：

- 按行业：教育、医疗、能源、政府、金融。
- 按项目类型：网络安全、等保测评、运维服务、软件开发、集成实施。
- 按材料用途：技术方案、服务承诺、项目案例、售后方案、实施计划。

**看这里：** 左侧会显示文件夹列表；选中文件夹后，右侧才可以上传文档。

## 第二步：上传文档

选中目标文件夹后，点击 **上传文档**。系统支持常见 Office、PDF、Markdown 和表格文件，例如 `.doc`、`.docx`、`.wps`、`.pdf`、`.md`、`.xls`、`.xlsx`。

上传后先不要急着使用，等待文档状态从 **等待处理 / 转换 Markdown / 抽取条目** 变成完成状态。

**看这里：**

- **进度条：** 显示当前文档处理进度。
- **状态标签：** 只有处理完成的文档才适合用于后续生成。
- **条目数量：** 显示系统从文档里拆出的知识条目数量。
- **候选数量 / block 数量：** 用于判断文档拆分是否充分。

## 第三步：检查解析结果

文档处理完成后，建议至少打开一次检查：

1. 点击 **查看条目**，检查系统拆出的知识条目是否完整。
2. 点击 **查看 Markdown**，检查原文结构、标题、表格和图片引用是否正常。
3. 如果处理失败，点击 **重试**；如果文档本身不适合复用，可以点击 **删除** 后重新上传更清晰的版本。

**看这里：** 如果 Markdown 里出现大量乱码、空白或表格错位，优先检查原文件是否能正常打开，必要时把扫描版转换为可复制文字后再上传。

## 第四步：在生成技术方案时引用知识库

知识库准备好后，进入 **标书生成 → 生成技术方案**，在 **目录生成** 的设置里勾选需要参考的知识库资料。

建议只勾选与本项目相关的资料。资料越精准，生成内容越容易贴近项目；资料过多、过杂，反而可能让正文跑偏。

**看这里：**

- 历史方案适合提供写法和结构。
- 项目案例适合补充经验、服务流程和实施方法。
- 公司标准材料适合补充服务承诺、质量保障和项目管理内容。
- 不确定能否复用的客户资料不要上传到公共知识库。

## 第二部分：维护工具模板库

在左侧点击 **知识库 → 工具模板库**。这里适合维护工具功能截图、软著证书、采购证明、产品说明、平台截图等材料。

操作顺序：

1. 点击 **+ 新增条目**。
2. 填写名称、备注、标签。
3. 上传一个或多个文件。
4. 点击 **保存**。
5. 回到列表后可通过 **搜索名称、备注或标签** 快速查找。

**看这里：** 工具模板库的重点是“可证明工具能力”。建议给截图和证书加清楚标签，例如“漏洞扫描”“日志审计”“资产测绘”“软著”“采购合同”。

## 第三部分：维护公司资质库

在左侧点击 **知识库 → 公司资质库**。这里适合维护营业执照、认证证书、资质证书、授权文件等公司材料。

操作顺序与工具模板库类似，但建议额外填写到期日。填写到期日后，系统会在列表和仪表盘里提示 **临期≤30天** 或 **已到期**。

**看这里：**

- 到期日明确的证书必须填写到期日。
- 长期有效的材料可以不填到期日，但要在备注里写清楚。
- 上传新版证书后，记得删除或备注旧版，避免投标时误用。

## 第四部分：维护人员资质库

在左侧点击 **知识库 → 人员资质库**。这里按“人员”建档，每个人可以维护多本证书。

操作顺序：

1. 点击 **+ 新增人员**。
2. 填写姓名、部门、岗位、电话、备注和标签。
3. 保存后点击人员记录进入详情。
4. 在详情里新增证书，填写证书名称、类别、取得日期、到期日和附件。
5. 通过 **临期≤30天**、**已到期** 快速筛选需要更新的证书。

**看这里：** 人员资质库适合维护项目经理、技术负责人、工程师、售后人员等投标常用人员材料。每本证书独立管理到期时间，不要只把所有证书打包成一个压缩文件。

## 使用建议

- 先分类，再上传；不要把所有资料堆在一个文件夹里。
- 上传后要检查 Markdown 或预览结果，不要只看“上传成功”。
- 与项目无关、涉密或客户限制传播的材料不要放入共享知识库。
- 做标书前先整理知识库，生成正文时再选择相关资料引用。
- 资质和证书要定期清理，避免投标时使用过期材料。
