# 功能清单与模块说明

本文件说明当前 GitHub Web 版的功能范围。它是可独立安装运行的 Web 形态，不包含 Electron 桌面壳、安装包生成和桌面自动更新。

## 1. 工作台与项目

- 仪表盘：展示项目统计、最近项目、资质到期提醒，帮助用户快速回到正在处理的标书项目。
- 多项目管理：项目数据按项目隔离，涉及项目作用域的接口由服务端校验归属。
- 后台任务与进度：长耗时任务通过服务端任务队列和 SSE 推送进度，前端只负责展示。

## 2. 标书生成

- 生成技术方案：上传招标文件，解析结构化内容，按步骤生成技术方案、章节内容和 Word 导出结果。
- 已有方案扩写：上传已有方案并扩充内容，目标是在保留原方案真实可落地内容的前提下补充厚度与表达。
- 投标计算器：由原“商务标”入口调整而来，模块简介为“综合报价、技术、商务评分标准计算标书最终得分”。当前入口仍保留原“正在开发中，敬请期待。”弹窗提示。
- 响应与偏离表工作台：复用当前项目的招标原文和分析结果，生成技术响应与偏离表；招标原文和人工响应字段不由 AI 随意改写。

## 3. 格式管理

- 我的模板：管理已保存的标书导出模板。
- 新建模板：配置 Word 文档排版、标题层级、编号规则和导出样式。
- 共享模板：管理员可维护共享模板，普通用户按权限使用。

## 4. 知识库与资产库

- 方案模板库：管理文档资料、案例素材和可复用知识条目。
- 工具模板库：管理工具截图、软著、采购证明等工具类资产。
- 公司资质库：管理公司证书、认证材料和到期提醒。
- 人员资质库：管理人员证书、认证材料和到期提醒。

## 5. 标书检查

- 标书查重：上传或导入标书内容后进行相似度与重复表达检测。
- 废标项检查：识别硬性条款、废标风险和响应完整性问题。

## 6. 使用文档与 FAQ

- 使用文档：内置 13 篇 Markdown 文档，分为“使用”“配置”和“FAQ”内容。全新安装或升级时可执行 `pnpm exec tsx prisma/seed-docs.ts` 写入数据库；脚本幂等，重复运行会刷新标题与正文，不覆盖管理员手动排序。
- 问题 FAQ：用户提交问题和图片附件，管理员回复、变更状态并沉淀常见问题。

## 7. 管理与配置

- 用户管理：注册审批、启停账号、管理员/普通用户角色、模块权限。
- 提示词管理：维护招标解析、废标检查等平台提示词，并支持恢复默认。
- 基本设置：初次部署默认系统名称为“易标投标工具箱web版”；管理员可修改系统名称和系统 Logo，登录页与顶栏实时读取。
- 深色/浅色模式：顶栏提供主题切换，支持浅色模式和参考 98 系统视觉迁移的 `soc-dark` 深色模式，选择保存在浏览器本地。
- 当前修改版源码入口：登录页与应用内开源说明保留当前修改版源码、原仓库、AGPL、NOTICE 和原作者归属。

## 8. 登录与权限

- 首次管理员强制改密：全新安装创建 `admin/admin` 后，只能先完成强密码修改，成功后才进入业务应用；重复 seed 不会重置已有管理员。
- 默认开放模块：仪表盘、标书生成、设置。
- 可授予普通用户的模块：格式管理、知识库、标书检查、使用文档、问题 FAQ。
- 管理员专属模块：用户管理、提示词管理。
- 权限约束同时存在于前端菜单/路由和后端模块门禁。前端隐藏不代替服务端鉴权。

## 9. 已移除或不包含

- 资源下载模块已从当前 Web 版移除：不再出现在主菜单、子菜单、普通用户可授予模块和默认功能介绍中。
- 本仓库不包含生产数据、测试数据、密钥、数据库备份、运行日志、客户标书和上传文件。
- 本仓库不包含原桌面版 Electron 安装包、桌面更新链路或闭源 vendor 二进制。
