# 功能清单

## Web 化与新增模块

- 仪表盘：项目统计、最近项目、资质到期提醒。
- 知识库：目录、文档、抽取、检索及公司共享资产。
- 问题 FAQ：用户发问、图片附件、管理员回复和状态管理。
- 用户管理：注册审批、启停、角色和模块权限。
- 提示词管理：平台提示词目录、编辑、恢复默认和播种。
- 基本设置：管理员修改系统名称和系统 Logo，登录页与顶栏实时读取。
- Web 后端：Fastify、Prisma、PostgreSQL、JWT、文件上传、SSE 和后台任务。

## 完整保留的业务模块

- 多项目管理
- 技术方案生成与已有方案扩写
- 响应与偏离表工作台
- 导出格式与共享模板
- 标书查重和废标项检查
- 使用文档和资源下载
- 工具库、公司资质库和人员资质库
- AI 诊断、任务恢复与 Word 导出

功能权限同时由前端菜单/路由和后端模块门禁约束。前端隐藏不代替服务端鉴权。
